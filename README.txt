# Sorting Algorithms Comparison Project


## Overview

This project compares the performance of three different sorting algorithms
applied to one and multi-dimensional arrays of various sizes. The goal is
to analyze and evaluate their efficiency based on time complexity depending
on arrays sizes.

The entire program is written in C, using dynamically allocated arrays.


## Features

- Implementation of three sorting algorithms
- Simple console menu that demonstrates correct sorting results for
different dimensions and algorithms. And time table results
- Detailed analysis of each sorting algorithms with diagrams in PDF report
document


## Skills and Technologies used

- Programming Language: C
- Dynamic memory management with pointers and malloc
- Multi-dimensional array handling
- Algorithm design and optimization
- Performance benchmarking and profiling
- Code documentation and reporting
